# Spec Kit — Casa da Paz (mínimo)

Templates em `.specify/templates/`. Skills Cursor em `.cursor/skills/speckit-*` (se instaladas).

## Ciclo obrigatório (features não-triviais)

1. `spec.md` — requisitos + acceptance  
2. `plan.md` — desenho técnico  
3. `tasks.md` — checklist + **V1/V2 datados**  
4. Implementar → validadores → memória

## Exceções

Hotfix / docs-only: só `spec.md` curto ou entry em project-memory.

## Validadores

- V1: `.cursor/skills/validador-integracao/SKILL.md`  
- V2: `.cursor/skills/validador-qualidade/SKILL.md`  

Registrar resultado em `specs/<feature>/tasks.md`.
