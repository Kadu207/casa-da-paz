# Playbook — Recepção e Check-in

## Fluxo gira
1. Abrir evento (status ABERTO)
2. Buscar consulente por telefone
3. Check-in médiuns (lista one-click)
4. Encerrar evento → contagens no dashboard

## Agendamentos públicos
1. Recepção vê fila `AgendamentoPublico` PENDENTE
2. Confirma → vincula ou cria `Pessoa`
3. N8N notifica consulente via Chatwoot
